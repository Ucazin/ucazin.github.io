Privacy Policy

Estudio Canais Lucca · Effective date: November 9, 2026

Home Terms of Service

Estudio Canais Lucca ("the tool") is a personal desktop script used only by its developer to upload and schedule the developer's own original videos on the developer's own YouTube channels. This policy explains what data the tool accesses and what it does with it.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

  • Basic information about the YouTube channels managed by the authorizing Google account (channel ID and title), to choose the destination channel.
  • The videos the tool itself uploads and their details (video ID, title, description, tags, scheduled publish time and processing status).
  • An OAuth authorization token issued by Google when the developer signs in and grants access.

The tool does not access data of any other YouTube user, and does not read email, contacts, comments, watch history or any other account data.

How the data is used

Only to upload, schedule and organize the developer's own videos on the developer's own channels, and to confirm that each upload went to the correct channel. The data is not used for advertising, profiling, analytics or training of machine-learning models.

Storage and security

The tool has no server. Everything runs on the developer's own computer. The OAuth token is stored in a local file on that computer, outside any shared folder or code repository, and is never sent anywhere except to Google's own servers when calling the API. The tool does not store YouTube API data beyond the current run, except the authorization token and a local list of the IDs of videos it uploaded, which is deleted or refreshed within 30 days.

Sharing

No data obtained through Google APIs is sold, shared with or transferred to any third party. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and this website

The tool itself does not use cookies. This website is a static page hosted on GitHub Pages; it sets no cookies and has no analytics. GitHub may log basic technical data of visitors as described in the GitHub Privacy Statement.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. Revoking access makes the stored token useless; deleting the local token file and the local list of video IDs removes all data the tool keeps. Videos already published remain on YouTube and can be managed or deleted in YouTube Studio.

Children

The tool is not directed to children and is not used by anyone other than its adult developer.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
